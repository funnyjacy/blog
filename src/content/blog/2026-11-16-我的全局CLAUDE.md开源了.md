用 Claude Code 这么久，我积累了一份越来越长的全局 CLAUDE.md——每次会话自动加载的那份「个人使用说明书」。现在把它开源到了 [funnyjacy/claude-md](https://github.com/funnyjacy/claude-md)，自取。

里面都是我使用Claude Code过程中积累的好用的实践构建：Windows 下读 PDF 的进程内负缓存怎么绕、PowerShell 5.1 传中文路径会乱码、MySQL 容器中文双重编码怎么预防、浏览器自动化该用 agent-browser 还是 chrome-devtools MCP……每一条都是真实踩坑后写下的，写一条少踩一次。

还有一部分是协作偏好：编辑文字前先给我看拟稿、commit 之前必须确认、调前端样式必须实际截图检查再交付、给外部仓库提 PR 前先跑一轮多视角审计。这些规则的意义在于把「信任」变成「流程」——AI 默认的行为不见得是我要的，那就把它写下来。

全文和 README 都在仓库里，欢迎参考：[github.com/funnyjacy/claude-md](https://github.com/funnyjacy/claude-md)
