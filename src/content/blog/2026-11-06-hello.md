博客开张。这里以后放随想和记录,按时间倒序排在首页。

写作方式:在 `src/content/blog/` 里新建一个 `.md` 文件,开头写上这三行——

```yaml
---
title: 标题
description: 一句话摘要(可选填)
pubDate: 2026-11-06
---
```

然后正文随便写 Markdown。写完 `git add` → `git commit` → `git push`,大约一分钟后网页上就能看到。

- 顶部「搜索」可以全文搜索所有文章
- 右上角按钮切换明暗模式
- 文章底部有评论(基于 GitHub Discussions)
